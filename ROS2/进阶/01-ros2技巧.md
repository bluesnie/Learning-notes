# ROS2技巧

## 1. ROS2 launch 启动时控制台输出颜色

- 方法一：`export RCUTILS_COLORIZED_OUTPUT=1`
- 方法二：修改`launch`文件

```python
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='your_package',
            executable='your_node',
            output='screen',
            emulate_tty=True,  # Enables color output by emulating a terminal
        )
    ])
```
